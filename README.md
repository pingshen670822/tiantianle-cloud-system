# 天天樂系統

## 操作入口

- 電腦更新：雙擊 `天天樂一鍵啟動.bat`，完成驗證後開啟 `site/index.html`。
- 手機雲端更新：雙擊 `天天樂雲端一鍵上線.bat`，送出 GitHub 更新要求；完成前保留上一份有效戰報。
- 手機網址：https://pingshen670822.github.io/tiantianle-cloud-system/
- `RUN_TIANTIANLE_NOW.bat`、兩個 `PUBLISH_*.bat` 及舊 Python 名稱僅為相容入口，沒有各自的更新或發布實作。

## 唯一更新流程

`system_update.py` → 作業系統互斥鎖 → SQLite 一致快照 → 隔離運算 → 驗證 → 可復原的正式資料置換。

正式資料、戰報與手機網站在驗證前不會被新運算覆寫。置換中斷時，復原日誌會在下一次啟動恢復一致狀態；保留一份上一版備份。

`cloud_update_request.py` 只送出同一套雲端流程的執行要求。已移除直接覆寫 gh-pages、切換 Pages 模式、失敗後仍宣告成功，以及多套修復程式互相改寫資料的舊實作。

## 保留的戰報規格

- 適用日期、終極獨隻、2中2、3中3、5中5、7中5、9中5。
- 1000組登錄配置與60期逐期回測：（19種預測方法＋1種隨機對照）× 10視窗 × 5種算法專用設定。
- 前15名六碼10組，以及1–39全號碼六碼最高分10組。
- 模型評分、命中紀錄及信心狀態分開標示；模型評分不等於中獎機率。

1000組配置定義在 `module1000.py`。各配置保留方法、視窗、算法專用設定、39號完整分數與排名、60期獨支命中、前五與前九平均命中及回放指紋。
每期只傳入當時已知的歷史前綴；完整執行兩輪重算，比對60個歷史排名指紋及本期排名。每輪60,000次歷史模組預測，不把參數變體或相同排名視為獨立證據；報告列出本期實際不同排名數量。
全39碼六碼前十名另外使用完整枚舉3,262,623種組合核對整數評分。單號百分比依950組預測配置排名重算，分母為950×39；50組隨機對照不投票。

## 自動更新

保留夏令與冬令開獎後更新、每三小時檢查、台灣13:00完整重算及21:45安全更新；已移除重複密集觸發。

主流程失敗時，救援工作呼叫同一套流程，不再執行另一套修改器。雲端依序執行測試、隔離重算、驗證、正式部署與網站同步核對。

排隊中的主流程及救援流程在實際開始時取得最新 `main`，避免沿用觸發當下的舊提交。提交前再次確認遠端版本；若計算期間有人修改主分支，停止發布，由救援流程以最新程式重新計算，禁止強制覆寫。

## 診斷與驗證

- 執行狀態：`work/update_status.json`。
- 最近一次更新紀錄：`logs/last_update.log`。
- 發布前驗證：`reports/repair_validation.json`。
- 上一版備份：`work/rollback-*`。
- 測試：`python -m unittest discover -s tests -v`。
- 只驗證：`python system_update.py --validate-only`。
- 完整重算：`python system_update.py --mode deep`。

外部開獎來源或託管服務暫時無法使用時，更新可能失敗；此時應查看紀錄並重試，不能將過期資料標為新一期，或將未通過驗證的輸出發布。


## 算法重寫 v2

舊版20×10×5把共同長期頻率排名混合作為變體，不能宣稱1000種算法。
新版是19種預測方法＋1種可重現隨機對照，共1000組參數實驗。
每種方法使用自身公式，未施加共同長期頻率混合；原始分數保留在JSON。
950組預測配置固定等權融合，50組隨機對照不參與推薦。

方法包括Beta頻率、指數濾波、OLS趨勢、CUSUM變點、Wilson下界、間隔核密度、
離散存活風險、延遲馬可夫、伯努利樸素貝氏、SGD邏輯迴歸、ridge AR(1)、
集合近鄰、形態近鄰、DFT週期外推、共現圖PageRank、尾數階層、星期分層、
線上專家及逆頻率對照。公式和設定位置見 `module1000.py`。

每個配置獨立重訓及評分，使用相同60個目標日以便公平比較，分三段各20期。
每種方法的固定代表預先設為90期視窗／設定2，不根據回測選參數。
候選模型頁列出各代表原始分數、逐期選號及命中、190對排名相關和前五交集。
雙輪重算是可重現驗證，不是兩份獨立的統計回測；60期不足以證實預測優勢。

補充驗證：每20期開始前固定模型，整段不重訓，形成三段保留測試；另做199次目標日期打亂對照並列出20代表的Holm調整。亂序檢定僅屬探索用途，不算另一批獨立資料。
